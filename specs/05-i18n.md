# 05 — Internationalization

## Languages

| Code      | Label (in the language selector) | Intl locale used for dates | Notes                                                   |
| --------- | -------------------------------- | -------------------------- | ------------------------------------------------------- |
| `en_US`   | English (US)                     | `en-US`                    | Reference language: defines the set of keys             |
| `fr_FR`   | Français (FR)                    | `fr-FR`                    | **Default language**                                    |
| `es_ES`   | Español (ES)                     | `es-ES`                    |                                                         |
| `it_IT`   | Italiano (IT)                    | `it-IT`                    |                                                         |
| `tlh_TLH` | tlhIngan Hol                     | `fr-FR` (fallback)         | Klingon, for fun. `tlh-TLH` is not a valid Intl locale. |

## Rules

| ID         | Requirement                                                                                                                                                                                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-I18N-01 | Every text shown to users MUST come from a translation table keyed by language code, then by text key. No user-facing text is hard-coded, except: the language labels, the "Changelog" dialog title, the version `v<x.y.z>` and the `–` placeholder of the absent toggle. |
| FR-I18N-02 | Every language MUST define **exactly the same keys** as `en_US`, with non-empty string values, except `confirmCheckOutPrefix` and `confirmCheckOutSuffix`, which MAY be empty (word order differs between languages). This is enforced by a test.                         |
| FR-I18N-03 | Placeholders are written `{count}` and `{names}` and replaced at runtime.                                                                                                                                                                                                 |
| FR-I18N-04 | Dates and times MUST be formatted with the Intl locale of the table above: date + time with `toLocaleString(locale)`, chart ticks with `toLocaleTimeString(locale, { hour: '2-digit', minute: '2-digit' })`.                                                              |
| FR-I18N-05 | An unknown language code (e.g. corrupted settings) MUST fall back to `fr_FR`.                                                                                                                                                                                             |
| FR-I18N-06 | Labels of options kept in the settings (status filter) MUST be recomputed from their value in the current language; stored labels are ignored.                                                                                                                            |
| FR-I18N-07 | Exported Excel files use the current language for column headers and values ([F06](functional/F06-export.md)).                                                                                                                                                            |
| FR-I18N-08 | The HTML document language is `en`.                                                                                                                                                                                                                                       |
